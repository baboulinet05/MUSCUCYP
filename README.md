# Carnet de fonte

Application de musculation personnelle (PWA pour iPhone) : séances, séries et répétitions, annuaire d'environ 1 600 exercices avec photos, animations et descriptions (dont machines Technogym et mobilité), routines, minuteur de repos, records et progression.

Ouvrir sur iPhone dans Safari, puis Partager → Sur l'écran d'accueil.

Photos d'exercices : [Free Exercise DB](https://github.com/yuhonas/free-exercise-db) (domaine public).
Animations et exercices supplémentaires : ExerciseDB, via [exercises-dataset](https://github.com/hasaneyldrm/exercises-dataset). Animations © Gym visual — https://gymvisual.com/ (180 × 180, usage personnel).
Les données d'entraînement restent sur le téléphone (Réglages → Exporter pour les sauvegarder).
